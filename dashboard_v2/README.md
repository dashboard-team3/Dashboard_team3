# pjL_v2 · Conflict Risk & Arms Dashboard (디자인 시험판)

원본 대시보드(`../pjL/app2.py`)를 복사해, 교수님 의견을 반영하고 **페이지마다 파일을 나눈** 판입니다.
원본은 건드리지 않았고, 화면에 나오는 자료 · 숫자 · 그래프 내용은 원본과 같습니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py --server.port 8503
```

**자료 찾는 순서** (`core/paths.py`)
- CSV 5개: 이 폴더 `data/` 에 있으면 그것, 없으면 원본 `../pjL/data`
- 실시간 수집 결과: `data/realtime/` → `../pjL/data/realtime/` → 둘 다 없으면 RDS 에서 읽음
- DB 접속 정보: 이 폴더 `.env` → 원본 `../pjL/.env` (**`.env` 는 절대 커밋하지 않음**, 비밀번호는 팀원끼리 직접 전달)

GitHub(Dashboard_team3)에서 받은 경우: `data/` 에 CSV 5개(`risk_monthly_1980_2026.csv` · `country_monthly_1980_2026.csv` ·
`region_monthly_1980_2026.csv` · `SIPRI_pre_1980_2025.csv` · `comtrade_mirror_detail.csv`)가 있어야 하고,
실시간 화면은 `.env` 를 만들어 두면 RDS 에서 읽습니다 (DB_HOST · DB_PORT · DB_USER · DB_PASSWORD · DB_NAME).

## 팀원이 페이지 고칠 때

| 고칠 페이지 | 파일 |
|---|---|
| ▶ 시작하기 | `views/start_view.py` |
| ① 실시간 모니터링 | `views/realtime_view.py` (자료 읽기 `sources/realtime.py`) |
| ② 리스크 분석 | `views/risk_view.py` (`sources/relations.py`) |
| ③ 무기 거래 추이 | `views/arms_view.py` (`sources/arms.py`) |
| ④ 리스크와 무기 거래 | `views/risk_arms_view.py` · 종합 분석은 `views/surge_view.py` (`sources/surge.py`) |
| ⑤ 데이터 소개 | `views/data_intro_view.py` |
| 색 · 글자 크기 · 카드 모양 | `styles/style2.css` · `styles/style_light.css` · `core/theme.py` (여러 페이지에 영향 → 먼저 말하기) |

같은 파일을 둘이 동시에 고치면 충돌이 나므로, 한 사람이 한 페이지 파일을 맡고 각자 브랜치에서 작업한 뒤 PR 로 합칩니다.

## 폴더 구성

```
pjL_v2/
├── app.py              진입점. 공통 설정 → 사이드바 → 고른 페이지 → 수집 시각 · 테마 동기화 (순서만)
├── core/               여러 페이지가 함께 쓰는 것
│   ├── paths.py          경로 (자료는 data/ → 없으면 ../pjL/data)
│   ├── setup.py          페이지 설정 · CSS 읽기 · 밝은 테마 · 테마 동기화
│   ├── ui.py             색 · 그래프 기본 설정 · 소제목 상자 · ⓘ 계산 기준 · 리스크 식
│   ├── sidebar.py        사이드바 제목 · 메뉴 · 페이지 필터 상자 · 맨 아래 수집 시각
│   └── theme.py          그래프 글꼴 · 글자 크기 · 밝은 테마 색 (모든 그래프가 거침)
├── views/              페이지마다 한 파일 (각각 page() 가 그 페이지 전체를 그림)
│   ├── start_view.py       ▶ 시작하기 (처음 보는 사람용 첫 화면)
│   ├── realtime_view.py    ① 실시간 모니터링
│   ├── risk_view.py        ② 리스크 분석 (국가쌍 · 국가별)
│   ├── arms_view.py        ③ 무기 거래 추이
│   ├── risk_arms_view.py   ④ 리스크와 무기 거래 개요 → [국가별 리스크와 무기 거래 | 중동 무기 거래 분석]
│   ├── surge_view.py       중동 무기 거래 분석 메뉴 (급증 분석, 나라 선택 없음)
│   └── data_intro_view.py  ⑤ 데이터 소개
├── sources/            자료 읽기 · 계산 (화면을 그리지 않음)
│   ├── realtime.py  relations.py  arms.py  surge.py
├── data/               CSV 5개 (GitHub 판) · realtime/ 는 커밋 안 함
├── styles/             style2.css (기본 어두운) · style_light.css (밝은 테마)
└── db/                 data.py (RDS 연결, 접속 정보는 .env → 없으면 ../pjL/.env) · global-bundle.pem
```

페이지를 고치려면 `views/` 의 그 페이지 파일만, 색 · 글자 크기 같은 공통 디자인은 `styles/` 와 `core/` 를 보면 됩니다.
