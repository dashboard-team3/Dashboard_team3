# GDELT_folder · 중동 16개국 분쟁 신호 분석

GDELT 1.0 뉴스 사건 데이터에서 **중동 16개국 사이의 위협 · 제재 · 무력 사용 사건**만 골라 날짜별 · 월별로 집계합니다.
팀원마다 **담당 월**을 나눠 처리하고, 월간 결과를 이 폴더에 모읍니다. 모은 결과는 `Dash_folder` 대시보드의 데이터로 사용합니다.

- 지원 기간: **2013년 4월 ~ 현재** (GDELT 일별 파일이 있는 기간)
- 원본 데이터는 저장소에 없습니다. 각자 PC에서 받습니다.

---

## 1. 처음 한 번만: 준비

### 필요한 것
- Python 3.9 이상
- pandas (`pip install pandas`)
- Git
- (선택) VS Code 또는 Jupyter — 노트북으로 하루치 분석을 따라가 볼 때만 필요

### 저장소 받기
OneDrive · 바탕화면 **밖**의 폴더에 받는 것을 권장합니다. (동기화 중 Git 파일이 잠기는 문제 방지)
```bash
git clone https://github.com/uuii006/Dashboard_team3.git
cd Dashboard_team3/GDELT_folder
```
- 비공개 저장소라 처음에 GitHub 로그인 창이 뜹니다. 저장소 초대(Collaborator)를 먼저 수락해야 합니다.

> 이후 모든 명령은 **`GDELT_folder` 폴더 안에서** 실행합니다.

## 2. 담당 월 처리하기 (3단계)

예시: **2019년 5월** 담당

### ① 최신 코드 받기
```bash
git pull
```

### ② 원본 데이터 받기
```bash
python download_gdelt_month.py 2019 5
```
- `data/2019.5_data/`에 하루 1개씩 zip 파일이 저장됩니다. **압축은 풀지 마세요.**
- 파일마다 서버 MD5로 손상 여부를 검사합니다.
- 중간에 끊겨도 다시 실행하면 받은 파일은 건너뛰고 이어서 받습니다.
- 용량: 최근 기준 한 달 약 170MB (과거일수록 작음)

마지막 줄이 이렇게 나오면 성공입니다.
```
완료: 새로 받음 31개, 이미 있음 0개, 실패 0개
```

### ③ 분석 실행
```bash
python run_month.py 2019 5
```
- 날짜마다 `20190501:   228건 저장` 같은 줄이 출력됩니다.
- 끝나면 월간 국가쌍 상위 10개가 표로 나옵니다.

### ④ 월간 결과 올리기
```bash
git add output/2019.5/월간
git commit -m "2019년 5월 월간 결과 추가"
git pull --rebase
git push
```
- **`output/2019.5/월간/` 폴더만** 올립니다. 날짜별 결과와 원본은 저장소 맨 위의 `.gitignore`로 자동 제외됩니다.
- 코드 파일(`.py`, `.ipynb`)을 고쳤다면 올리지 말고 팀과 먼저 상의하세요.
- `git push`가 거절되면 다른 팀원이 먼저 올린 것입니다. `git pull --rebase` 후 다시 `git push` 하세요.

## 3. 결과 파일

### 폴더 구조
```
Dashboard_team3/
├─ .gitignore                        ← 원본 · 날짜별 결과를 GitHub에서 제외
├─ Dash_folder/                      ← Streamlit 대시보드
└─ GDELT_folder/                     ← 이 폴더
     ├─ README.md
     ├─ download_gdelt_month.py      ← ② 원본 받기
     ├─ run_month.py                 ← ③ 월 단위 분석
     ├─ GDELT_중동분석_최종.ipynb      ← 하루치 분석을 단계별로 보는 학습용 노트북
     ├─ data/                        ← 원본 (각자 PC에만, GitHub에 안 올라감)
     │    └─ 2019.5_data/
     │         └─ 20190501.export.CSV.zip …
     └─ output/
          └─ 2019.5/
               ├─ 20190501/ …        ← 날짜별 결과 (각자 PC에만)
               └─ 월간/              ← 월간 결과 (GitHub에 올림)
```
`data/`, `output/` 폴더는 처음 실행할 때 자동으로 만들어집니다.

### 날짜 폴더 `output/2019.5/20190501/` (3개)
| 파일 | 내용 |
|---|---|
| `GDELT_20190501_중동_선택EventCode_필터링.csv` | 조건에 맞는 사건 목록 (날짜, 국가, 사건 코드, 언급 수, 논조, 위치, 기사 URL) |
| `GDELT_20190501_중동_국가쌍_EventCode별_이벤트수.csv` | 국가쌍 × 사건 코드별 건수 |
| `GDELT_20190501_중동_국가쌍별_QuadClass.csv` | 국가쌍별 언어적 갈등(3) · 물질적 갈등(4) · 전체 건수 |

### 월간 폴더 `output/2019.5/월간/` (4개)
| 파일 | 내용 |
|---|---|
| `GDELT_2019.5_월간_중동_선택EventCode_필터링.csv` | 한 달치 사건 목록 전체 |
| `GDELT_2019.5_월간_중동_국가쌍_EventCode별_이벤트수.csv` | 한 달 국가쌍 × 사건 코드별 건수 |
| `GDELT_2019.5_월간_중동_국가쌍별_QuadClass.csv` | 한 달 국가쌍별 건수 (**국가쌍 전체 건수는 `total_event_count`**) |
| `GDELT_2019.5_월간_중동_일별_국가쌍_이벤트수.csv` | 국가쌍 × 날짜별 건수 (추이 그래프용) |

모든 CSV는 엑셀에서 한글이 깨지지 않도록 `utf-8-sig`로 저장됩니다.

## 4. 분석 기준

모든 팀원이 같은 기준으로 처리해야 결과를 합칠 수 있습니다. **기준을 바꾸려면 팀 합의 후 코드를 수정하세요.**

| 항목 | 기준 |
|---|---|
| 국가 | 행위자(`Actor1CountryCode`)와 대상(`Actor2CountryCode`)이 **모두** 아래 16개국 |
| 자국 내 사건 | 제외 (`ISR → ISR` 등) |
| 방향 | 유지 (`ISR → IRN`과 `IRN → ISR`은 다른 국가쌍) |
| 사건 날짜 | 파일 날짜 기준 **7일 이내** 사건만 (과거 사건을 언급한 기사 제외) |
| 사건 코드 | 아래 20개 |
| 중복 | 월간 합산 시 `GLOBALEVENTID` 기준 중복 제거 |

**16개국 (CAMEO 코드)**
사우디아라비아 `SAU` · 아랍에미리트 `UAE` · 카타르 `QAT` · 쿠웨이트 `KUW` · 바레인 `BHR` · 오만 `OMA` · 예멘 `YEM` · 시리아 `SYR` · 레바논 `LBN` · 요르단 `JOR` · 이스라엘 `ISR` · 팔레스타인 `PSE` · 이라크 `IRQ` · 이란 `IRN` · 이집트 `EGY` · 튀르키예 `TUR`

**사건 코드 20개**

## 5. 노트북으로 하루치 분석 따라가기 (선택)

`GDELT_중동분석_최종.ipynb`는 `run_month.py`와 같은 기준을 **단계별로 풀어 쓴 학습용**입니다.

1. VS Code에서 `GDELT_folder/GDELT_중동분석_최종.ipynb`를 엽니다. 노트북은 **자기 파일이 있는 폴더(`GDELT_folder`)** 를 기준으로 `data`, `output`을 찾습니다. 0번 셀을 실행해 출력되는 경로가 `…/GDELT_folder/data/…`인지 확인하세요.
2. 0번 셀의 `DATE = "20190501"`처럼 원본이 있는 날짜로 바꿉니다.
3. 전체 실행하면 1~7단계 결과가 `output/2019.5/20190501/`에 저장됩니다.
4. 8번 셀(`RUN_MONTH`)도 월 단위 처리를 할 수 있지만, **월 처리는 `run_month.py` 사용을 권장합니다.**
5. 코드에 `✏️ [수정 N]` 표시가 있는 곳은 원본 노트북에서 고친 부분이며, 맨 위 표에 이유가 정리돼 있습니다.

> ⚠️ 노트북의 `DATE`를 바꾼 채로 커밋하면 팀원끼리 충돌이 납니다. 노트북 변경은 올리지 마세요.
> 되돌리기: `git restore GDELT_중동분석_최종.ipynb`

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| `2013년 4월 이전은 일별 파일이 없어 지원하지 않습니다.` | 2013년 3월 이전은 원본 형식이 달라 현재 코드로 처리할 수 없습니다. |
| `처리한 날짜가 없습니다.` | ② 원본 받기를 먼저 실행했는지, 연·월 숫자가 같은지 확인하세요. |
| `20190512: 원본 없음 → 건너뜀` | 해당 날짜 zip이 없습니다. ②를 다시 실행하세요. 서버에 파일이 없는 날도 드물게 있습니다. |
| 다운로드 `실패` 표시 | 네트워크 문제일 수 있습니다. 같은 명령을 다시 실행하면 실패한 날짜만 다시 받습니다. |
| 노트북에 `⚠️ 현재 폴더에 data · output 폴더가 없습니다` | 원본을 아직 받지 않았거나, 노트북이 `GDELT_folder`가 아닌 곳을 기준으로 실행 중입니다. 0번 셀이 출력한 경로를 확인하세요. |
| `git push`가 거절됨 | 다른 팀원이 먼저 올린 것입니다. `git pull --rebase` 후 다시 `git push` 하세요. |
| 원본을 받지 않고 서버에서 바로 읽고 싶음 | `python run_month.py 2019 5 --server` (원본은 저장되지 않음, 매번 다시 읽음) |

## 7. 해석할 때 주의

- GDELT는 **보도된 사건**을 자동 추출한 데이터입니다. 실제 사건 수가 아니며, 한 기사가 여러 사건으로 잡히기도 합니다.
- 연도마다 수집 기사량이 크게 다릅니다. 서로 다른 해의 **건수를 그대로 비교하지 말고** 비율로 보정해야 합니다.
- 하마스 · 헤즈볼라 같은 무장단체도 소속 국가 코드로 기록됩니다.
- 무기 거래 등 다른 데이터와 함께 볼 때는 인과가 아닌 "함께 움직인 패턴"으로 해석합니다.
